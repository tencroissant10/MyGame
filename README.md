# ランキング予想ゲーム

出題者が5つの選択肢を好きな順に並べ、ほかの参加者がその順位を当てるオンラインのパーティーゲームです。

## 起動方法

Node.js 18以上が必要です。追加のライブラリはいりません（`npm install` も不要です）。

```
node server.js
```

- このPCで遊ぶ場合: http://localhost:3000
- 同じWi-Fiにつながっているスマホで遊ぶ場合: 起動時に表示される `http://192.168.x.x:3000`。ロビー画面の共有リンクとQRコードは、自動でこのアドレスになります。
- 離れた場所の友達と遊ぶ場合: Render や Railway など Node.js が動くサービスにこのフォルダをデプロイします（`npm start` で起動、ポートは環境変数 `PORT` で指定）。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `server.js` | ルーム管理、ゲーム進行、得点計算、リアルタイム同期（SSE） |
| `topics.js` | お題45個（1つのお題に選択肢5個） |
| `public/index.html` | 画面（スマホとPCの両方に対応） |

## 仕様のポイント

- **入室**: 部屋主がルームを作ると、4桁のルーム番号・リンク・QRコードが表示されます。参加者が入力するのはニックネームだけです。
- **秘匿**: 出題者のランキングと各参加者の予想は、答え合わせになるまでサーバーから送信されません（開発者ツールで見ても分かりません）。
- **不正防止**: 同じ順位に2つ置くことはできません。予想の二重送信、部屋主以外による開始操作、ゲーム中の途中参加はサーバー側で拒否します。
- **得点**: 順位が1つ当たるごとに1pt、5つすべて当たると7ptです。
- **相性No.1ペア**: 2人がお互いのランキングを当てた個数の合計が最も多いペアです。同点の場合は複数のペアを発表します。
- **再接続**: リロードしたり、スマホがスリープから戻ったりしても、同じプレイヤーとして復帰できます。
- **進行の救済**: 部屋主は、応答しない出題者をスキップしたり、未回答の人を待たずに答え合わせに進んだりできます。
- **再戦**: 最終結果の画面で部屋主が「もう一度遊ぶ」を押すと、ポイントと相性がリセットされ、同じルーム・同じメンバーでロビーに戻ります。

※ ルームの情報はサーバーのメモリに保存されるため、サーバーを再起動すると消えます。
